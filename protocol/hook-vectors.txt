# Local hook channel vectors (laptop only, not the phone link). Read by shared/Edgepad.Core.Tests/HookClientTests.cs and the
# Swift hook client tests (CLIENT lines), shared/Edgepad.Core.Tests/HookProtocolTests.cs and the Swift HookProtocolTests
# (SERVER lines).
#
# Lines starting with # and blank lines are ignored. A line is cut at the FIRST " => ". No escapes beyond JSON's own: every
# JSON value below is read by a JSON parser exactly as written, so "\n" inside a JSON string is a line feed.
#
#   CLIENT <agent> <kind> <input> => <request JSON without "token"> | NONE
#       The hook client, the app run as `<app> --hook <agent> <kind>`, with <input> on stdin for perm and session, or as the
#       next argument for usage and spend. NONE: nothing is sent. The request is compared as JSON (key order free).
#
#   SERVER <request line> => <parse JSON> | NONE
#       The laptop's HookProtocol.TryParse of the request line. NONE: not a request; the connection closes with no reply.
#       The parse is compared as JSON (key order free):
#         perm     {"kind":"perm","agent","token","session","cwd","tool","command","file_path","url","command_safe","truncated","text"}
#         session  {"kind":"session","agent","token","session","event","cwd","notification_type"}
#         usage    {"kind":"usage","agent","token","windows":[{"window","pct","resets_at"}],"context"}
#         spend    {"kind":"spend","agent","token","today":[tok,cents],"week":[tok,cents],"month":[tok,cents]}
#       Absent optional values are null. session and cwd are "" when absent. command_safe is false only for a Codex
#       array-form command with a control character inside an element (the laptop then offers Deny only). An array command
#       is joined with spaces, each element that is empty or holds whitespace, ' or " written in POSIX single quotes with
#       every ' inside as '\'' (so ["sh","-c","a b"] is sh -c 'a b').
#       text is PermissionBroker.TextFor: what the phone would show. Claude: Bash command; Edit, Write, MultiEdit, Read,
#       NotebookEdit file_path; WebFetch url; any other tool null. Codex: the first of command, file_path, url. null too when
#       that field is absent or "". A null text is deferred at once: the phone is never asked to approve what it cannot show.
#       truncated: the hook client sent "truncated":true in d (it cut a field to 5000 characters; it sends the key only then;
#       any non-boolean value is NONE), or the laptop cut a field to 16384 characters (tested in code). A truncated request
#       is Deny only on the phone.
#       Limits: tool_name 1..24 of A-Za-z0-9_.-; JSON depth <= 8; line <= 64 KiB (tested in code); v must be the number 1.
