# Dashboard wire vectors, read by the C# (shared/Edgepad.Core.Tests/DashWireTests.cs), Kotlin and Swift suites. One line per case:
#
#     CODEC arguments => expected
#
# Lines starting with # and blank lines are ignored. The line is cut at the FIRST " => ". Everything after "CODEC " up to
# that is the arguments; everything after it is the expected text, compared exactly.
#
# Escapes, in the arguments and in the expected text alike (a UTF-8 file; any other character stands for itself):
#     \t  tab        \n  line feed        \\  one backslash
#     \u{HEX}  the code point HEX (1 to 6 hex digits)
#     \{N*c}   N copies of the one code point c (so a 4097-byte case does not need 4097 characters in the file)
# Markers: "<empty>" as a whole field or a whole expected text is the empty string; "<none>" as the expected text means the
# input is rejected (a single record did not parse). A list is never rejected as a whole: an entry that does not parse or
# is not allowed is dropped, so a list with none left is "<empty>".
# Fields of an entry are separated by " @ ", entries by " ;; ". Only the last field of PERMASK may itself contain " @ ".
#
# Codecs (encoders take records, the "*PARSE" codecs take wire text and expect the canonical wire text it re-encodes to):
#   CLEAN n text              Clean(text, n): control characters (Cc), space, "|", "/", ":", bidi and zero-width characters
#                             (every code point in Unicode categories Cf, Zl, Zp: e.g. U+200B-200F, U+202A-202E, U+2066-2069,
#                             U+FEFF, U+061C, U+180E, U+2028, U+2029, U+2060-2064, U+E0000-E007F) become a space; runs collapse; trim; cut to n
#                             code points (never inside a surrogate pair); trim again.
#   CLEANTEXT text            CleanText(text): keeps \n and \t, drops other control characters, shows the bidi and zero-width
#                             characters above as <U+XXXX> (upper-case hex, at least 4 digits). No trim, no cut.
#   STATS c,r,g,v,d,u,p,l,ct,gt,gp          eleven integers; percents (cpu ram gpu vram loss) clamp to 0..100, any negative is -1;
#                             the rest: negative is -1.
#   STATSINFO cpu ;; ramMiB ;; gpu ;; vramMiB ;; net      names Clean(30), shrunk together until the payload fits 255 bytes; a
#                             negative MiB is -1. STATSINFOPARSE needs exactly five "|" fields and integers.
#   DISKS label @ usedPct @ totalGiB @ freeGiB ;; ...     label Clean(16), empty becomes "-"; used clamps 0..100 (negative -1);
#                             total and free negative -1; at most 6 entries; trailing entries dropped until 255 bytes.
#   SESSIONS agent @ state @ title ;; ...                 agent claude|codex, state busy|wait|idle (else dropped); title
#                             Clean(24); at most 8; trailing entries dropped until 255 bytes.
#   PERMANSWER wire           => "allow ID" | "deny ID" | <none>. Exactly 12 lowercase hex, "/", then "a" or "d", nothing else.
#   PERMLABEL id flag         => "id/flag"; PERMLABELPARSE wire => "id flag" | <none>.
#   PERMASK agent @ tool @ text   => "F body". F is 1 when complete, 0 when the body would pass 4096 bytes (then the text is
#                             empty). tool: every char outside A-Za-z0-9_.- becomes "_", cut to 24, empty becomes "unknown".
#                             body is agent, tool and CleanText(text) joined by line feeds.
#   PERMASKPARSE body         => "agent @ tool @ text" | <none>. Agent known, tool 1..24 of A-Za-z0-9_.-, body <= 4096 bytes.
#   LIMITS agent @ window @ pct @ resetAtMin @ measuredAtMin ;; ...   window: canonical decimal 1..525600, "ctx", or "~" and a
#                             name (Clean(16), not empty); anything else drops the entry. pct (a decimal) clamps 0..100 and
#                             rounds half up. A negative time is -1. Trailing entries dropped until 255 bytes.
#   SPEND agent @ measuredAtMin @ tokToday @ centsToday @ tokWeek @ centsWeek @ tokMonth @ centsMonth ;; ...   64-bit
#                             integers; measuredAtMin negative is -1, the rest negative is 0. Trailing entries dropped to 255.
#   WEATHER tempTenthsC @ wmoCode @ city   temp clamps -999..999, a wmo outside 0..99 is -1, city Clean(24). "WEATHER none" is
#                             the empty payload.
#   GITHUB section @ repo @ number @ title @ flags @ ci ;; ...   section R|M|N (else dropped). For R and M the repo must be
#                             owner/name (each 1..100 of A-Za-z0-9_.-), number >= 0, title Clean(80), flags "d" or nothing,
#                             ci ok|fail|pending|none (anything else is none). An N line is always "N", empty, the count,
#                             empty, empty, "none". At most 10 lines per section; trailing lines dropped until 8192 bytes.
#                             Lines are joined by line feeds, fields by tabs.
