# Which app in front is which kind of app, for TEXT 40 FOREGROUND_KIND. Read by the laptop apps, never sent over the phone link:
# only the kind token (APP_KIND_TOKEN in actions.txt) crosses it, never a title.
#
# Format:  APP_KIND <kind> <os> <token>
# kind is an APP_KIND_TOKEN; os is windows, linux or macos. The token is exactly what that OS's foreground reporter emits for
# the app, matched case-insensitively: Windows the exe file name with .exe, Linux the WM_CLASS class (X11 only), macOS the
# bundle id. A token has only A-Za-z0-9._-, so an exe name with a space (Adobe Premiere Pro.exe, Ableton Live 12 Suite.exe,
# Adobe After Effects) can never be emitted and is left out.
# Order of the check: this table, then a playing media session, then a browser. macOS follows only Music and Spotify, so a
# browser in front is "browser" there, never "media".
# A row not seen on a real device ends in "# unverified"; the owner reviews them.
