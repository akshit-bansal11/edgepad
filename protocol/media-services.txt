# Which service is playing, for the media card's logo. Read by the three laptop apps and the phone's tests; never sent
# over the link as a table: the laptop sends only the service's name, in the place it sends the media app's name, and
# the phone draws its bundled logo for that name.
#
# Format:  SERVICE <name>|<match>[,<match>...]
# name   exactly what the laptop sends; the phone's AppLogo must have a logo for every name below unless the row ends in
#        "# no logo", and then the phone shows its plain music/video symbol.
# match  title:<words>  the words stand as their own word in a browser tab or window title, case-insensitive: nothing
#                       that is a letter or digit right before or right after ("Plex" is never read out of "complexity").
#        host:<host>    the page's address is this host or a sub-domain of it (macOS and Linux read the address).
#        app:<token>    a media session's app id or exe name holds this, case-insensitive (desktop apps, not browsers).
#
# Rows are tried in order and the first match wins, so a longer name comes before a shorter one it contains
# ("YouTube Music" before "YouTube", "Apple TV+" before "Apple TV"). A browser with no matching row shows the plain symbol,
# never the browser's own icon. A row not seen on a real device ends in "# unverified"; the owner reviews them.
