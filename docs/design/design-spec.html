Edgepad
Design Specification

The brand, the colours, the type, the spacing, the components and the motion of Edgepad 4.0, on the phone, the laptop, the website and in video.

Version 4.0.0 · October 2026 · github.com/akshit-bansal11/edgepad
Every value in this document is read from the shipped code. Where this document and the code disagree, the code wins.

1 Principles

Edgepad is a tool you reach for from across a room. The design serves that.

  • Calm by default, blue when it matters. One accent colour, used only for what is selected, on, live, or the main action. Everything else is ink, grey and soft surfaces.
  • Readable at a glance. Dials read like a progress bar bent around a corner; values are set in Lato Black so they read from arm's length.
  • iOS-like grouped surfaces. A soft ground, white grouped cards on it, rounded corners, hairline separators.
  • Never glare in the dark. Dark mode is a soft near-black with off-white ink, never pure #000 and #FFF.
  • Accessible first. Every text pair meets 4.5:1 contrast or better; every touch target is at least 48 dp.

Use

  • Choose the variant for contrast with what is behind it. On a light ground use the dark tile; on a dark ground use the light tile. Where the system follows a theme (Android launcher, Windows and Linux tray, Mac menu bar and Dock on macOS 26, the website favicon), the icon switches with it.
  • Clear space: at least one eighth of the tile's width on every side.
  • Smallest size: 16 px. Below 24 px the tray uses a one-colour dial (Mac) or the rendered sizes 16–48 px (Windows, Linux).
  • Never recolour the glyph, outline it, add effects, rotate it, or set it on a busy photograph.
  • Files: the SVG masters in assets/; PNGs at 1024, 512 and 256 px in assets/brand/; app icons rendered by scripts/icons.sh.

Wordmark

“Edgepad” set in Lato Black (900), ink, with tracking −0.01 em. Beside the mark, the wordmark's cap height matches 45% of the tile's height and sits 0.3 × tile width from it.

4 Typography

Lato everywhere, in three weights: 400 for reading, 700 for labels and buttons, 900 for titles and the numbers a dial shows. JetBrains Mono only for real code on the website.

6 Components

Corner dial

Each corner of the control surface is a dial that wraps around the edge; sliding along it changes the level. With Split corners on (Settings › Corners), every corner holds a dial on each of the two edges it joins: eight in all.

Now playing

A 280 × 52 dp piece on the surface showing the source's logo (40 dp), the title and the source. Play is a 52 dp accent circle with skip buttons 52 dp either side; the piece can be dragged anywhere on the pad.

Macro deck

Up to fifteen macros. Buttons have no fill and no border: an icon and a Lato Bold label. The grid picks the largest buttons that fit (three macros show large, fifteen small), and a short last row is centred. Press and hold to drag; a grid picker (Automatic, or a fixed rows × columns) sits under the deck in edit mode.

Rows, cards and controls

  • Grouped card: card colour, 14 dp corners, 16 dp padding, hairline separators between 52 dp rows.
  • Switch: accent when on, off when off.
  • Segmented control: faint track, card thumb, SMALL labels.
  • Buttons: full-width 50 dp, accent fill with on_accent label; secondary buttons faint.
  • Lock: a locked pad is tinted with the accent at 16% across a 44 dp band, so a locked pad never looks like a working one.

Iconography

Lucide icons (ISC licence), 24-unit grid, 2-unit strokes with round caps and joins, drawn from Lucide's own paths in every app. The licence text ships inside the APK and the exe.

7 Motion

  • Purposeful and short. State changes ease out; nothing loops for decoration.
  • Reduced motion is honoured on the website: content appears without movement.
  • Dials respond instantly to the finger; animation never delays input.

9 Voice and copy

  • Plain, second person, short sentences. Say what a thing does, then stop.
  • Name controls exactly as the app does: Split corners, Controls, Annotate, Sign, Capture, Forget trusted phones.
  • Be honest about limits: Mac and Linux are still in testing; Bluetooth does not reach the next room.
  • Never publish a latency figure until the app's own round-trip readout reports one from real devices.
  • Never fabricate a review, a statistic or a testimonial.
