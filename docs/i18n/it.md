# Italian (it) glossary

Android `values-it`, Windows culture `it`. Natural Italian as Italian Android and Windows write it.

## Register and conventions

- **Register:** informal "tu", in both apps. Buttons use the short imperative forms Italian Android itself uses ("Annulla", "Salva", "Elimina", "Connetti", "Riprova"); titles and labels are nouns or noun phrases. Deviation from the brief's "infinitive": Italian Android and Windows buttons are imperatives, not infinitives, so those are used.
- **Titles and labels:** sentence case ("Impostazioni dell'area di controllo").
- **Apostrophes:** `\'` in Android XML (l'app, dell'evento); plain `'` in resx.
- **Quotes:** « » for quoted names in resx (`«{0}»`). Menu and button names quoted inside running text are written bare, capitalised, as the menu shows them.
- **Numbers and units:** regular space before units (`5 ms`, `60 Hz`, `1 MB`, `120 dp`); `%` attached (`50%`).
- **Plurals:** one / many / other. `many` is for millions and takes "di" after the number ("1 000 000 di secondi").
- **Gender:** "portatile" is masculine (connesso, memorizzato, attivo). "Mac" masculine. "macro", "forma", "cattura" feminine.
- **Key caps:** Ctrl, Alt, Maiusc (Shift), Fn, Esc, Canc, Invio, Home, Fine, Pag↑, Pag↓, Bloc Maiusc. Windows logo key as Windows labels it.
- **Dial short labels:** VOL, LUM, ZOOM, BRANO, APP, HZ, SCORR, ORIZ, DESK, TAB, PORT.
- **Fonts:** Lato covers Italian; no system-font override.
