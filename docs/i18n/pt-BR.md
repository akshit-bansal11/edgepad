# Brazilian Portuguese (pt-BR) glossary

Android `values-pt-rBR`, Windows culture `pt-BR`. Everyday Brazilian usage, as the phone's and Windows' own UI write it.

## Register and conventions

- **Register:** "você", in the imperative for actions ("Toque", "Escolha", "Digite"). No "tu", no European forms ("telemóvel", "ecrã", "ficheiro").
- **Titles and labels:** sentence case ("Configurações da superfície"). Buttons are imperative verbs or short nouns ("Conectar", "Esquecer").
- **Quotes:** curly quotes “ ” for menu items, settings and file-dialog names quoted inside a sentence (“Macros…”, “Conexões Wi-Fi e USB”, “Tethering USB”).
- **Numbers and units:** a regular space before units (`5 ms`, `60 Hz`, `1 MB`, `120 dp`); `%` attached to the number (`50%`). Decimal separator handled by the system.
- **Plurals:** one / many / other. `one` covers 0 and 1; `many` is for millions and takes "de" after the number ("1 000 000 de segundos").
- **Gender:** "notebook" is masculine (conectado, lembrado, ativo). "celular" is masculine. "Mac" masculine.
- **Laptop word:** "notebook", the common Brazilian word; "computador" only where the English says computer. "Celular" for the phone, never "telefone" or "telemóvel".
- **Settings word:** "Configurações" (Android and Windows pt-BR).
- **Key caps:** Ctrl, Alt, Shift, Fn, Esc, Del, Enter, Home, End, Page Up, Page Down, Caps Lock (Brazilian keyboards print the English names). Arrow keys as ↑ ↓. Windows logo key left as Windows labels it.
- **Dial short labels:** VOL, BRILHO, ZOOM, AVANÇO, APPS, TAXA, ROLAR, LADO, ÁREAS, ABAS, NOTE.
- **Windows access keys:** tray menu I, M, S, W, F, B, T, Z, D, R, A, E (unique); Security window P, E, R, S; Macros window A, P, E, U, R, S.
