# Korean (ko)

Android `values-ko`, Windows culture `ko` (UI font Malgun Gothic; Android uses the system font, see `fonts.xml`).

## Register

Polite 해요체 (-어요/-아요) for every sentence, in both apps, as Samsung One UI and Windows 11 Korean write messages. Labels, titles, tabs and menu items are bare nouns ("볼륨", "모서리", "클립보드 공유"); buttons are nouns or short verb-noun phrases ("연결", "연결 해제", "다시 시도"). Instructions use the polite imperative (-하세요). No 합쇼체 (-습니다) anywhere. No deviation from the brief.

## Conventions

- Latin stays: Edgepad, Wi-Fi, USB, Windows, Android, Mac, GitHub, ViGEmBus, Xbox, (preset names are translated: 플랫포머 / 레이싱 / 슈팅; `gamepad_preset_*`), PIN, units (`dp`, `Hz`, `MB`, `ms`), `F1`-`F12`, Ctrl, Alt, Shift, Fn (Korean keyboards print these in Latin). Bluetooth is written 블루투스 in running text; the untranslatable `transport_bluetooth` and the connection-type placeholder stay `Bluetooth`.
- Particles after placeholders: a name, number or connection type is never followed by a particle that depends on its last sound. Used instead: 에 / 에서 / 의 / 부터 / 도 (no vowel/consonant alternation), a colon ("제어하기: %1$s"), parentheses ("노트북(%1$s)의"), or the placeholder is put last. `로` after the connection type is safe for Bluetooth, Wi-Fi and USB (all end in a vowel when read).
- Quote marks: curly ‘…’ for a quoted menu item; no apostrophes. Ellipsis `…`.
- Number and unit: space for `dp`, `MB`, `Hz`, `ms` ("30 dp"); counters attached ("3개", "5초", "2분"); percent attached ("50%").
- Plurals: `other` only. `pin_attempts_left` etc. keep the number.
- Joiners: `list_separator` ", ", `sentences_joined` "%1$s %2$s", `corner_slot` "%1$s · %2$s".
- Dial short labels: 볼륨, 밝기, 확대, 탐색, 앱, Hz, 세로, 가로, 데스크, 탭, 노트북.
- Windows access keys: Latin letter in parentheses at the end ("매크로(&M)…"); the ellipsis follows it. Tray menu letters: T M E W F B S C L U D Q; Security window: P F R S; Macros window: A B C U R S.
- "Left/right/up/down" are physical: 왼쪽, 오른쪽, 위쪽, 아래쪽.
